# spec

The specification that every Roadbook tool is built against, kept separate from the design documents so that it can be versioned and tested. It holds the IR's JSON Schema ([`ir.schema.json`](ir.schema.json)) and its field-by-field reference ([`ir.md`](ir.md)), which the compiler, the viewer, both runtimes and the code generators all read; the execution rules both runtimes implement ([`execution.md`](execution.md)); the trace format ([`trace.md`](trace.md), [`trace.schema.json`](trace.schema.json)); the saved snapshot format ([`snapshot.schema.json`](snapshot.schema.json), described in [`execution.md`](execution.md#saving-and-restoring)); and the [conformance cases](conformance/) (charts, scripts and expected traces that both runtimes must reproduce byte for byte). The language reference comes next.
